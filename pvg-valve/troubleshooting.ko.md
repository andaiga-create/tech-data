## 압력·유량 이상 점검

| 증상 | 우선 확인 |
|---|---|
| 전체 기능 압력이 낮음 | Main Relief / PVP 설정, 펌프 압력 |
| 특정 기능만 압력이 낮음 | 해당 LSA/LSB 설정, A/B 포트 |
| 특정 기능 속도가 느림 | Speed Control, 유량, 스풀 작동 |
| 특정 기능 속도가 빠름 | Speed Control 설정 |
| 부하에 따라 동작이 불안정함 | LS 신호, Pressure Control Spool 적용 여부 |
| 압력은 정상인데 유량이 부족함 | Speed Control, 스풀 스트로크, 펌프 유량 |

> ⚠ Pressure Control Spool은 크레인의 lifting/lowering 및 slewing에서 발생할 수 있는 LS 제어 불안정 문제를 줄이는 용도로 사용된다.
