## Troubleshooting

검색 Keyword: DX series, 온도조절계, OOOO, UUUU, LBA, Auto-tuning, AT lamp, 알람

### 증상: PV 표시부에 `OOOO` 또는 `UUUU` 표시

**Possible Cause**
- 입력 레인지 초과(센서 실제 값이 최대/최소 스케일을 벗어남)
- 서픽스 코드상 입력 타입과 실제 연결된 센서 타입 불일치
- 입력 센서 단선 또는 배선 극성 반대

**Inspection**
- [ ] 명판/서픽스 코드의 입력 타입(K, J, R, Pt100 등)과 실제 센서 확인
- [ ] 입력 단자대 배선 극성 및 체결 상태 확인
- [ ] 센서 저항/전압을 테스터로 실측하여 단선 여부 확인

**Corrective Action**
1. 입력 타입 불일치 시 SL1(초기 설정 모드)에서 올바른 입력 타입으로 재설정
2. 배선 극성 오류 또는 단선 시 재결선/케이블 교체
3. 전원 재투입 후 PV 표시 정상 여부 재확인

**Final Check**
정상 상태에서 PV가 실제 온도와 근접한 값으로 안정적으로 표시되는지 확인한다.

### 증상: Auto-tuning이 완료되지 않고 AT 램프가 계속 점멸

**Possible Cause**
- 히터/쿨러가 실제로 동작하지 않음(출력 배선 불량, 액추에이터 고장)
- 제어 동작 방향(SL9) 설정 오류(가열/냉각 반대 설정)

**Inspection**
- [ ] 제어출력 인가 시 히터/쿨러가 실제로 동작하는지 확인(전류계/온도 변화로 확인)
- [ ] SL9 제어 동작 방향 설정값 확인

**Corrective Action**
1. 출력 배선 및 액추에이터(SSR, 전자접촉기, 히터) 점검 및 수리
2. SL9 설정을 실제 용도(가열/냉각)에 맞게 재설정
3. 오토튜닝 재실행

### 증상: Loop Break Alarm(LBA) 경보 발생

**Possible Cause**
- 히터 단선 또는 SSR/릴레이 고장으로 제어출력이 부하에 전달되지 않음
- LBA Time 설정이 실제 시스템 응답 속도보다 짧게 설정됨
- 센서 이탈(온도 검출부가 실제 대상물에서 분리됨)

**Inspection**
- [ ] 히터 저항 측정(단선 여부)
- [ ] SSR/릴레이 출력단 전압·통전 확인
- [ ] 센서 삽입 위치 및 고정 상태 확인
- [ ] LBA Time 설정값 확인

**Corrective Action**
1. 단선된 히터 또는 고장 난 출력 소자 교체
2. 센서 재삽입 및 고정
3. 필요 시 LBA Time을 시스템 열용량에 맞게 재조정
4. LBA 리셋 후 정상 동작 재확인

### 증상: High/Low Alarm 램프가 계속 점등

**Possible Cause**
- 실제 프로세스 온도가 알람 설정값(SL13/SL14) 범위를 벗어남
- 알람 설정값 자체가 부적절하게 설정됨
- 센서 드리프트(경년 오차)

**Inspection**
- [ ] 실제 온도와 PV 표시값 비교(별도 온도계로 교차 검증)
- [ ] 알람 설정값(고온/저온) 확인
- [ ] 센서 노후화/오차 여부 확인(필요 시 캘리브레이션)

**Corrective Action**
1. 실제 공정 이상(과열/과냉)일 경우 해당 원인 조치 우선
2. 알람 설정값이 부적절하면 실제 운전 범위에 맞게 재설정
3. 센서 드리프트가 의심되면 센서 교체 또는 캘리브레이션 실시
