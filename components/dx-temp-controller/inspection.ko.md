## Inspection

작업 전 아래 항목을 순서대로 확인한다.

> ⚠ 전원을 차단하지 않은 상태에서 배선 작업을 하면 감전 및 오동작 위험이 있다. 반드시 Power OFF 후 작업하고, 릴레이 출력 배선은 부하 용량(정격 전류/전압) 이내인지 반드시 확인한다.

- [ ] Power OFF 확인
- [ ] 입력 센서(열전대/RTD 등) 배선 및 극성 확인 — 명판/서픽스 코드의 입력 타입과 실제 센서 타입 일치 여부
- [ ] 출력 배선(릴레이/SSR/전류출력) 단자 체결 상태 확인
- [ ] 판넬 매입 고정 상태 및 절연 확인
- [ ] 표시부(PV/SV) 오염, 파손, 응결 여부 확인
- [ ] 각종 램프(OUT, AT, ALM1, ALM2, LBA) 점등 상태 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| PV 표시 | 실제 온도에 비례하여 정상 표시 | `OOOO`(입력 최대 레인지 초과) 또는 `UUUU`(입력 최소 레인지 초과) 표시 |
| 센서 배선 | 완전 체결, 피복 손상 없음 | 단선, 접촉불량, 극성 반대 결선 |
| 출력 램프(OUT) | 제어 동작에 따라 정상 점멸 | 점등 고정 또는 완전 소등(무반응) |
| AT 램프 | 오토튜닝 중에만 점멸, 완료 후 소등 | 장시간 소등되지 않고 계속 점멸 |
| LBA 표시등 | 정상 시 소등 | 제어루프 이상 시 점등(Loop Break 발생) |

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능. ABNORMAL 항목 발생 시 아래 Troubleshooting 절차로 이동한다.
