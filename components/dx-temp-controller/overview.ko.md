## 개요

DX Series는 **한영넉스(HANYOUNG NUX)**의 디지털 온도조절계(Digital Temperature Controller)로, PID 제어 방식을 기반으로 현재 측정값(PV)과 설정값(SV)을 동시에 표시하며, 릴레이·SSR 전압펄스·전류출력 등을 통해 히터 또는 쿨러를 구동한다.

> ℹ 본 자료는 제조사 제공 취급설명서(국문/영문)를 기준으로 작성되었다. 실제 설치된 모델의 서픽스 코드(Suffix Code)에 따라 입력 타입, 출력 방식, 옵션이 달라지므로 반드시 현품 명판을 함께 확인한다.

### 주요 기능

- PV(측정값) / SV(설정값) 동시 표시
- Auto-tuning(AT) 기능을 통한 PID 파라미터 자동 설정
- Loop Break Alarm(LBA) — 제어루프 단선/이상 감지
- High/Low Alarm(고온/저온 경보) 및 편차·프로세스 알람 모드 선택
- 다양한 입력 타입 지원: K, J, R, B, S, T, W, C 열전대, Pt100/Pt10 RTD, DC 전압(1-5V, 0-10V), DC 전류(4-20mA), 커스텀 입력
- 릴레이 접점, SSR 전압펄스, 전류출력(4-20mA) 중 선택 가능한 제어출력
- 옵션: 통신(RS485), 재전송 출력(Retransmission Output)

### 설치 위치

크레인 제어반(Control Panel) 내부에 매입(埋入) 방식으로 장착되며, 히터 또는 쿨러의 온도를 제어하는 용도로 사용된다. 판넬 컷아웃 규격은 크기 코드(DX4/DX6/DX7/DX9)에 따라 다르므로, 교체 시 반드시 모델 코드를 확인한 후 동일 사이즈로 교체한다.
