## Setting

### 모드 진입 방법

| 모드 | 진입 방법 | 설명 |
|---|---|---|
| PV/SV 설정 모드 | [MODE] 키를 짧게 누름 | SV(설정값) 입력, 통상 운전 중 사용 |
| 초기 설정 모드 (SL1/SL2/SL3) | [MODE] + [▲] 키를 3초간 동시에 누름 | 입력 타입, 출력 타입, 알람 모드 등 최초 설정. 이후 [MODE] 키를 3초간 눌러 진입하는 경우도 있음(모델 버전에 따라 상이) |
| 주요 기능 설정 모드(SL4~SL15) | [MODE] 키를 4초 이상 계속 누름 | 소수점 위치, 입력 보정, 알람 설정, LBA 등 세부 파라미터 설정 |

> ℹ SL1~SL15 전체 파라미터의 세부 설정값은 표 형태 자료의 인식 정확도 한계로 이 문서에 전체 수록하지 않았다. 정확한 파라미터 코드와 설정 범위는 첨부된 원본 매뉴얼 PDF의 "각부의 기능 및 명칭" / "주요 기능 설명" 표를 반드시 확인한다.

### Auto-tuning(AT) 절차

1. PV/SV 모드에서 [MODE] 키를 3초 이상 눌러 오토튜닝을 시작한다.
2. AT 램프가 점멸하며 오토튜닝이 진행된다(PID 파라미터 P, I, D 및 ARW 값을 자동 산출).
3. 오토튜닝이 정상 완료되면 AT 램프가 자동으로 소등된다.
4. 오토튜닝을 중도에 취소하려면 동일하게 [MODE] 키를 3초 이상 눌러 AT 램프를 소등시킨다.

> ℹ 오토튜닝은 목표 SV의 약 2/3 지점부터 시작되며, 히터/쿨러가 실제로 반응하는 상태에서 실시해야 정확한 결과를 얻을 수 있다.

### 제어 동작 방향 (SL9)

| 설정값 | 의미 |
|---|---|
| 0 | 역동작(Reverse) — 가열(Heating) 제어 |
| 1 | 정동작(Direct) — 냉각(Cooling) 제어 |

### Loop Break Alarm(LBA) 설정

제어 출력이 나가고 있음에도 PV(측정값)가 지정된 시간(LBA Time) 동안 지정된 변화율 이상 변하지 않으면 LBA가 작동한다. 히터 단선, 액추에이터 고장, 센서 이탈 등을 감지하는 데 사용된다.

### 설정 완료 후 확인 기준(Acceptance Criteria)

- PV가 SV 대비 설정 허용오차 이내로 안정화되는지 확인
- AT 램프가 완전히 소등되어 있는지 확인
- ALM1/ALM2/LBA 램프가 정상 상태(비작동 시 소등)인지 확인
- 전원 재투입 후 모델 표시(예: `dX9`) 및 버전(`V0.1`)이 정상적으로 표시되는지 확인
