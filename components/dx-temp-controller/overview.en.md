## Overview

The DX Series is a **HANYOUNG NUX** digital temperature controller. It uses PID control to display the Process Value (PV) and Set Value (SV) simultaneously, and drives a heater or cooler through a relay, SSR voltage-pulse, or current output.

> ℹ This reference is based on the manufacturer's Korean/English instruction manuals. Input type, output type, and options vary by the unit's Suffix Code, so always cross-check the nameplate on the actual installed unit.

### Key functions

- Simultaneous PV (measured value) / SV (set value) display
- Auto-tuning (AT) function for automatic PID parameter setup
- Loop Break Alarm (LBA) — detects control-loop break or abnormality
- High/Low alarm with selectable deviation/process alarm mode
- Wide input support: K, J, R, B, S, T, W, C thermocouples, Pt100/Pt10 RTD, DC voltage (1-5V, 0-10V), DC current (4-20mA), custom input
- Selectable control output: relay contact, SSR voltage pulse, or current output (4-20mA)
- Options: communication (RS485), retransmission output

### Mounting location

Flush-mounted in the crane control panel, used to control heater or cooler temperature. Panel cutout size differs by dimension code (DX4/DX6/DX7/DX9) — always confirm the model code before replacing a unit to ensure the cutout size matches.
