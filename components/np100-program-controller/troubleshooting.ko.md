## Troubleshooting

검색 Keyword: NP100, 프로그램컨트롤러, 온도오차, 노이즈, 설정 초기화, 경보, 릴레이 수명, 번-아웃

> ℹ 아래 증상/조치는 제조사 매뉴얼 "1. 안전상 주의사항"에 명시된 원인들을 근거로 구성되었다.

### 증상: 전원 ON/OFF 반복 후 설정값이 임의로 바뀌어 있음(오동작)

**Possible Cause**
- 전원 스위치를 자주 ON/OFF하는 회로 구성에서 스위치 채터링으로 인해 마이크로컴퓨터 기억 수치가 초기화됨
- 강한 외부 노이즈로 인한 오동작

**Inspection**
- [ ] 조절계 조작전원이 빈번한 ON/OFF가 발생하는 회로에 직접 연결되어 있는지 확인
- [ ] 계기 전원선이 촘촘하게 꼬여 있는지, 노이즈 필터/절연트랜스 적용 여부 확인

**Corrective Action**
1. 조절계 전원을 자주 ON/OFF되는 회로가 아닌 상시 전원 계통으로 재배선
2. 노이즈가 많은 환경에서는 절연트랜스 및 노이즈 필터 적용(필터는 패널에 접지, 필터 출력측 배선은 짧게)
3. 전원 재투입 후 반드시 설정값(파라미터)을 재확인

---

### 증상: 온도 표시값에 오차가 발생함 (실제 온도와 차이)

**Possible Cause**
- 열전대 입력에 소정의 보상도선을 사용하지 않고 일반 도선을 사용함
- 측온저항체(RTD) 입력의 3선 리드선 저항이 서로 다르거나 저항값이 큼
- 온도보상(rJC) 설정이 OFF로 되어 있음(열전대 입력 시)

**Inspection**
- [ ] 열전대 배선에 지정된 보상도선 사용 여부 확인
- [ ] RTD 3선 리드선 저항이 동일한지 측정
- [ ] 입력설정그룹의 rJC(온도보상) 설정값 확인

**Corrective Action**
1. 보상도선으로 재배선
2. RTD 리드선을 저항이 작고 3선간 저항차가 없는 것으로 교체
3. 열전대 입력 시 rJC를 ON으로 설정

---

### 증상: 경보(AL1/AL2)가 원치 않는 시점에 동작하거나 전혀 동작하지 않음

**Possible Cause**
- 경보종류선택(A1TY/A2TY) 또는 경보설정치(AL-1/AL-2)가 실제 운전조건과 맞지 않음
- 정접/역접 선택 오류(역접 선택 시 표시램프 ON일 때 출력은 OFF로 동작)

**Inspection**
- [ ] 경보설정그룹(G.ALn)의 종류·설정치·데드밴드 확인
- [ ] 정접/역접 경보 코드(1~10 vs 5,6,9,10 등)가 의도와 일치하는지 확인
- [ ] 운전 전 반드시 경보 동작을 시험 확인

**Corrective Action**
1. 경보 종류 및 설정치를 재설정
2. 정접/역접 경보의 출력 논리를 재확인 후 필요 시 코드 변경

---

### 증상: 릴레이 접점 출력의 수명이 짧아짐(빈번한 접점 고장)

**Possible Cause**
- 비례동작 등 동작빈도가 높은 조건에서 릴레이 접점 정격에 여유 없이 부하를 직접 접속

**Inspection**
- [ ] 가열싸이클타임(Ct) 설정값 확인 (전자 개폐기 사용 시 20초 이상, SSR 사용 시 1초 이상 권장)
- [ ] 부하가 릴레이 접점 정격(240V AC 3A 또는 30V DC 3A, 저항부하) 이내인지 확인

**Corrective Action**
1. 보조 릴레이를 매개하여 부하를 개폐
2. 가능하면 SSR 구동 출력 타입으로 변경
3. 직류 유도성 부하에는 CR 필터(교류) 또는 다이오드(직류)를 병렬 접속

---

### 증상: 히터단선 경보가 정상적으로 동작하지 않음

**Possible Cause**
- 히터전원과 조절계 전원이 서로 다른 전원선에 결선되어 있음

**Inspection**
- [ ] 히타단선 경보 사용 시, 히터전원과 조절계(조작) 전원이 동일 전원선에서 분기되었는지 확인

**Corrective Action**
1. 히터전원과 조절계 전원을 동일 전원선으로 재결선

---

### 증상: PV 표시가 최댓값 또는 최솟값으로 고정 표시됨(번-아웃)

**Possible Cause**
- 입력센서(열전대/RTD) 단선
- 번-아웃 동작선택(boUt)이 UP 또는 DOWN으로 설정된 상태에서 실제 단선 발생

**Inspection**
- [ ] 센서 배선 단선 여부 실측 확인
- [ ] 입력설정그룹의 boUt 설정 확인(OFF/UP/DOWN)

**Corrective Action**
1. 단선된 센서 또는 배선 교체
2. 재발 방지를 위해 배선 경로 및 고정 상태 점검

---

### 증상: 계기를 예비품으로 교체한 후 제어 동작이 이전과 달라짐

**Possible Cause**
- 형명(모델)이 동일해도 개별 계기의 설정 파라미터가 서로 다를 수 있음

**Inspection**
- [ ] 교체 전후 엔지니어링모드/프로그램모드의 전체 설정값을 비교

**Corrective Action**
1. 교체 전 기존 계기의 전체 파라미터를 "12. 프로그램 설정차트"에 기록해 두고, 교체 후 동일하게 재설정
2. 호환성 확인 후 운전 재개
