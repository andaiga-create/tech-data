## Setting

> ⚠ 조절계의 운전시 준비작업은 반드시 엔지니어링모드에서 실행한다. 엔지니어링 모드 설정은 **입력 → 출력 → 그 외 그룹** 순서로 진행해야 하며, 순서를 지키지 않고 입력그룹 또는 출력그룹의 데이터를 나중에 변경하면 이미 설정된 다른 그룹의 데이터가 초기화될 수 있다.

### 모드 진입/이동

| 동작 | 방법 |
|---|---|
| 운전표시모드 → 엔지니어링모드 | SET 키를 2.5초 이상 누름 (G.EnG 표시) |
| 엔지니어링그룹 ↔ 프로그램그룹 | G.EnG/G.Pro 화면에서 STEP(▲)/HOLD(▼) 키로 전환 |
| 그룹 내부 진입 | SET 키 |
| 그룹 간 이동 | STEP(▲) / HOLD(▼) 키 |
| 상위 그룹으로 복귀 | < (좌측 이동) 키 |
| 자릿수(Digit) 위치 이동 | < 키 |
| 설정값 저장 후 다음 항목 이동 | 값 변경 후 SET 키 |
| 프로그램 진행 중 세그먼트 일시정지/해제 | < + HOLD 키 동시 입력 |
| 프로그램 진행 중 다음 세그먼트로 강제 진행 | < + STEP 키 동시 입력 |
| 패턴번호 변경 | P1/P2 키 |
| 자동/수동 전환 | AUTO/MAN 키 |
| 현재 프로그램 종료 및 운전정지 | RST 키 |

### 조작키 기능 요약

| 키 | 기능 |
|---|---|
| RUN | 현재 선택된 패턴번호를 운전 시작 |
| SET | 설정값 입력·확정, 파라미터 간 이동, 2.5초 이상 누르면 운전표시모드↔엔지니어링모드 전환 |
| RST | 진행 중인 프로그램/MAN운전 종료 및 정지·리셋 상태로 전환, 프로그램 설정모드 종료 |
| < | 수정할 Digit 위치 변경 |
| STEP(▲) | 파라미터 값 변경, 그룹 간 이동 |
| HOLD(▼) | 파라미터 값 변경, 그룹 간 이동 |
| P1/P2 | 패턴번호 변경(누를 때마다 전환) |
| AUTO/MAN | 프로그램 운전 ↔ 수동(MAN) 제어 전환 |

**설정 절차 요약**

1. 엔지니어링모드 설정을 모두 마친 후 STEP/HOLD로 프로그램모드(G.Pro)로 이동한다.
2. 리피트횟수(G.rPt) 또는 패턴 설정(G.Pt)으로 진입한다.
3. 패턴번호(Pt.no)를 선택하고, "0"세그먼트에서 스타트값/스타트종류/타임시그널/프로그램완료시모드 등 패턴 공통 조건을 설정한다.
4. 세그먼트 1부터 순서대로 PID그룹·목표설정값·세그먼트시간을 설정하며, 최대 10세그먼트까지 반복한다.
5. SET 키를 2.5초 이상 눌러 운전모드로 복귀하고, RUN 키로 프로그램 운전을 시작한다.

> ℹ 프로그램완료시 모드: 1패턴 완료 후 PT-1을 선택하면 반복횟수까지 운전 후 리셋(단, HOLD는 마지막 값 유지), PT-2를 선택하면 패턴1→패턴2로 연결 운전한다. 2패턴 완료 시 모드를 PT-2로 선택하면 패턴2가 리피트횟수만큼 반복 운전한다.

### 설정 완료 후 확인 기준(Acceptance Criteria)
