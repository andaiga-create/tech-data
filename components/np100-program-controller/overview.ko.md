## 개요

NP100은 **한영넉스(HANYOUNG NUX)**의 프로그램 컨트롤러(멀티 입·출력 프로그램 온도조절계)로, 목표온도를 시간에 따라 단계적으로(패턴/세그먼트) 변화시키며 제어하는 온도조절계이다. 단순 정치제어뿐 아니라 승온·유지·강온 구간을 조합한 온도 프로파일(램프/소크) 제어가 필요한 설비에 사용된다.

> ℹ 본 자료는 제조사 국문 취급설명서를 기준으로 작성되었으며, 영문 매뉴얼은 제공되지 않아 본 문서의 영문 버전은 국문 원문을 번역한 것이다. 정확한 수치나 배선은 반드시 첨부된 원본 국문 PDF를 함께 확인한다.

### 3가지 동작 모드

| 모드 | 진입 시점 | 설명 |
|---|---|---|
| 운전표시모드 | 전원 ON 시 기본 표시 | 측정치(PV)/설정치(SV), 측정치/출력량, 프로그램 운전시 세그먼트 잔류시간을 표시 |
| 엔지니어링모드 | SET 키 2.5초 이상 누름 | 입력(센서) 종류, 출력 종류, 통신, 전송, 경보, 제어동작, PID, 오토튜닝 등 계기의 기본사양을 설정 |
| 프로그램모드 | 엔지니어링모드에서 STEP/HOLD로 이동 | 프로그램 반복횟수, 패턴번호, 세그먼트 설정, 프로그램 스타트 조건, 타임시그널, 프로그램 종료시 모드, 세그먼트별 파라미터 설정 |

### 주요 특징

| 기능 | 내용 |
|---|---|
| 선택사양 | RS485/422, 타임시그널 2점 |
| 측정치 표시 | 4행 표시, 측정정도 ±0.1%, 측정주기 250ms, 멀티입력 지원 |
| 제어출력 | 멀티출력(전류/전압펄스, 릴레이) |
| 전송출력 | 전류 또는 SPS(외부센서용 전원), RET 단자 겸용 |
| 경보출력 | 릴레이 2점 |
| 타임시그널 출력 | 트랜지스터 2점 |
| 총 PT수 / 총 SEG | 2 패턴 / 20 세그먼트 (패턴당 최대 10세그먼트) |
| 통신 | RS485/422, 600~9600bps, 최대 31대/라인 |
| 전원 | 100-240V AC, 50-60Hz |

### 모델 코드 구성 (형명구성)

`NP100-□□` 형식이며, 첫 번째 자리는 제어종류(0=일반형/가열), 두 번째 자리는 선택사양이다.

| 코드 | 내용 |
|---|---|
| 0 | 선택사양 없음 |
| 1 | 타임시그널 2점 |
| 2 | 통신(RS485/422) |
| 3 | 타임시그널 2점 및 통신(RS485/422) |

### 설치 위치

크레인/호이스트 제어반 내부에 매입 장착되어, 히터/쿨러 등 열원의 온도를 시간 프로파일에 따라 제어하는 용도로 사용된다. 패널 컷아웃은 92.0×92.0mm(허용공차 +0.8/0), 패널 두께 2~10mm 강판을 권장한다.

> ⚠ 입출력 단자는 감전 위험이 있으므로 신체 및 통전물이 절대로 접촉되지 않도록 한다. 배선은 반드시 전원을 차단한 후 실시한다.
