## Specifications

### 9-1. 입력 사양

| 항목 | 규격 |
|---|---|
| 입력채널수 | 1채널 |
| 입력종류 | 열전대, 측온저항체, 직류전압 |
| 입력레인지 | 열전대/측온저항체는 표의 온도범위 내에서 변경 가능, 직류전압은 각 레인지 범위 내에서 최소/최대 전압 가변 |
| 샘플링 주기 | 250ms |
| 입력저항 | 열전대/mV 입력: 1MΩ 이상, DCV 입력: 약 1MΩ |
| 허용신호원 저항 | 열전대입력: 250Ω 이하, mV/DCV 입력: 2kΩ 이하 |
| 허용배선저항 | RTD 입력: 10Ω 이하/1선 |
| 허용입력전압 | mV/TC/RTD: ±10V, DCV: ±20V |
| 잡음제거비 | NMRR: 40dB 이상(50/60Hz ±1%), CMRR: 12dB 이상(50/60Hz ±1%) |
| 적용규격 | TC/RTD(JIS/IEC/DIN) |
| 기준접점보상오차 | ±1.5℃(15~35℃), ±2.0℃(0~50℃) |
| 번아웃검출기능 | OFF/UP SCALE/DOWN SCALE 선택 가능, TC Burn-out 시 UP/DOWN SCALE, RTD Burn-out 시 UP SCALE, 검출전류 약 50nA |
| 측정정도 | ±0.1% of F.S |

### 9-2. 제어출력 (Control Output)

| 출력 종류 | 규격 |
|---|---|
| 릴레이접점출력 | 접점용량 240V AC 3A / 30V DC 3A(저항부하), 접점구성 1c, 시간비례 또는 ON/OFF 동작, 싸이클타임 1~1000초, 출력리미트 0.0~100.0%(상한/하한 설정 가능), ON/OFF 제어 시 히스테리시스 0~100% |
| SSR출력(전압펄스출력) | ON전압 약 25V DC 이상(600Ω 이상 부하, 단락 시 약 30mA 제한), OFF전압 0.1V DC 이하, 싸이클타임 1~1000초, 출력리미트 0.0~100.0% |
| SCR출력(전류출력, 4-20mA DC) | 출력전류범위 4-20mA DC, 출력경신주기 250ms, 저항부하 600Ω 이하, 연속 PID 동작, 출력리플 0.1% of FS(p-p) 이하(150Hz), 정도 ±0.3% of FS, 출력리미트 -0.5~105.0% |

### 9-3. 경보출력

| 항목 | 규격 |
|---|---|
| 릴레이출력 | 접점용량 240V AC 1A / 30V DC 1A(저항부하), 설정점수 1a × 2, 동작 ON/OFF, 데드밴드 0.0~100.0%(EUS) |

### 9-4. 전송출력

| 항목 | 규격 |

| 부하저항 | 600Ω 이하 |
| 정도 | ±0.3% of FS |
| 분해능 | 약 3000 |

| 전압변동율 영향(정격전압범위 내) | 아날로그 입력 ±1μV/10V 또는 ±0.01% of FS/10V, 아날로그 출력 ±0.05% of FS/10V 이하 |
