## Inspection

작업 전 아래 항목을 순서대로 확인한다.

> ⚠ 입출력 단자는 감전 위험이 있다. 배선 작업 전 반드시 조절계 본체 및 외부공급전원을 차단하고, 연결된 케이블에 통전되지 않음을 테스터 등으로 확인한 후 작업한다.

- [ ] Power OFF 확인 및 배선 결선 상태(단자 극성) 확인
- [ ] 사용 입력센서 종류와 입력설정그룹(G.In)의 설정이 일치하는지 확인
- [ ] 접지 배선 확인 (2㎟ 이상 굵은 전선, 제3종 접지 이상, 접지저항 100Ω 이하, 케이블 길이 20m 이내)
- [ ] 전면 LED 표시 상태 확인 (RUN/WAIT/HOLD/MAN, AL1/AL2, TS1/TS2, OUT, AT, SEG1~10)
- [ ] 패널 고정 상태 확인 (고정대 2개, 고정 토크 약 14.7 N·cm)

### 개별 LED 기능

| 표시 LED | 기능 |
|---|---|
| RUN | 프로그램 운전 실행 시 점등 |
| WAIT | 프로그램 운전 중 웨이트(WAIT) 동작 실행 시 점등 |
| HOLD | 프로그램 운전 중 홀드(HOLD) 동작 시 점등 |
| MAN | 수동 운전 시 점등 |
| AL1 / AL2 | 제1/제2 경보 동작 시 점등 |
| TS1 / TS2 | 타임신호 1/2 동작 시 점등 |
| OUT | 제어출력이 ON일 때 점등 |
| AT | 오토튜닝 중 점멸 |
| SEG1~10 | 프로그램 운전 중 현재 진행 중인 세그먼트를 표시 |
| PT1 / PT2 | 패턴1 / 패턴2가 선택되었을 때 점등 |
| ▲(상승) / ━(유지) / ▼(하강) | 세그먼트가 각각 상승구간/유지(Soak)구간/하강구간일 때 점등 |

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| PV 표시 | 실제 온도에 비례하여 정상 표시 | 번-아웃(입력 단선) 시 설정된 UP/DOWN SCALE 방향으로 고정 표시 |
| RUN LED | 프로그램 운전 중 점등, 정지 중 소등 | 운전 명령 후에도 점등되지 않음 |
| AT LED | 오토튜닝 중에만 점멸, 완료 후 소등 | 장시간 점멸 지속 |
| 경보(AL1/AL2) | 설정된 조건에서만 동작 | 정상 범위에서도 지속 경보 또는 이상 시 무반응 |

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능. ABNORMAL 항목 발생 시 아래 Troubleshooting 절차로 이동한다.
