# PVG 32 Setting Guide

## 1. PVP Pressure Relief
Catalog setting range:
- With PVSI end plate: 30–350 bar
- With PVS end plate: 30–300 bar

Set according to the actual system requirement and allowable pressure of the complete configuration.

## 2. LSA / LSB Pressure Limiting
Recommended conditions to avoid interaction with PVLP:
- PVLP ≤ 150 bar → LSA/B ≤ 0.8 × PVLP
- PVLP > 150 bar → PVLP − LSA/B ≥ 30 bar

## 3. PVLP
PVLP is a shock/suction valve and is not designed to be used as a pressure relief valve. If a working function requires pressure limiting, use a PVB configuration with adjustable LSA/B pressure limiting valves.

## 4. Pressure Control Spool
For crane lifting/lowering and slewing functions showing instability or oscillation, pressure-control spool application may be considered.

The catalog describes a half pressure-control spool for main lifting/lowering and a full pressure-control spool as an example for cylinder slewing.

## 5. Before Setting
- Complete PVG No.
- PVP / PVB / PVBS code
- Pump type: fixed / variable displacement
- PVS / PVSI
- PVLP and LSA/B settings
- Pilot pressure
- Actual pressure-gauge readings

> Actual system design requirements take priority. Catalog values should be used as configuration and selection references.
