# PVG 32 Inspection Checklist

## A. Identification
- [ ] Confirm PVG 32
- [ ] Full valve-group photo
- [ ] Nameplate / PVG No. photo
- [ ] PVP code
- [ ] Number of PVB sections
- [ ] PVBS code
- [ ] Actuator type

## B. Hydraulic
- [ ] P pressure
- [ ] LS pressure
- [ ] T back pressure
- [ ] A/B pressure
- [ ] PVP relief setting
- [ ] LSA/B setting
- [ ] PVLP setting
- [ ] Pilot pressure
- [ ] Oil temperature
- [ ] Oil cleanliness

## C. Electrical
- [ ] Supply voltage
- [ ] Connector
- [ ] Neutral signal
- [ ] A/B command
- [ ] Fault output / LED
- [ ] CAN communication(PVED)
- [ ] Spool-position feedback

## D. Functional
- [ ] No unintended movement in neutral
- [ ] A-direction operation
- [ ] B-direction operation
- [ ] Float operation, if applicable
- [ ] Load holding
- [ ] LS response
- [ ] PVPX unloading
- [ ] Emergency lowering, if PVPC is configured

## E. Records
Record actual measured values, valve codes, photographs and setting values during every inspection.
