# PVG 32 Setting Guide

## 1. PVP Pressure Relief
카탈로그 기준 PVP pressure relief valve setting range:
- PVSI End Plate: 30–350 bar
- PVS End Plate: 30–300 bar

설정은 실제 시스템 요구압력과 구성품의 허용압력을 기준으로 수행한다.

## 2. LSA / LSB Pressure Limiting
PVLP 설정압과 LSA/B 설정에는 상호 간섭 방지 조건이 있다.

- PVLP ≤ 150 bar → LSA/B ≤ 0.8 × PVLP
- PVLP > 150 bar → PVLP − LSA/B ≥ 30 bar

## 3. PVLP
PVLP는 Shock/Suction Valve이며 압력 릴리프 밸브로 사용하도록 설계된 것이 아니다. Working function의 pressure limiting이 필요하면 PVB의 adjustable LSA/B pressure limiting valve 구성을 검토한다.

## 4. Pressure Control Spool
Crane의 Lifting/Lowering 및 Slewing에서 진동/불안정이 발생하는 경우 pressure-control spool 적용을 검토할 수 있다.

Main lifting/lowering에서는 Half Pressure Control Spool, Cylinder Slewing에서는 Full Pressure Control Spool이 카탈로그의 대표 적용 예이다.

## 5. 설정 전 확인
- Valve Group의 전체 PVG No.
- PVP / PVB / PVBS Code
- Pump type: Fixed / Variable displacement
- PVS / PVSI
- PVLP 및 LSA/B setting
- Pilot pressure
- 실제 시스템 pressure gauge 값

> 설정값은 현장 시스템 설계값을 우선하며, 카탈로그 값은 구성 가능 범위와 선정 기준으로 사용한다.
