# PVG 32 Inspection Checklist

## A. Identification
- [ ] PVG 32 확인
- [ ] 전체 Valve Group 사진
- [ ] Nameplate / PVG No. 사진
- [ ] PVP Code
- [ ] PVB Section 수
- [ ] PVBS Code
- [ ] Actuator Type

## B. Hydraulic
- [ ] P Pressure
- [ ] LS Pressure
- [ ] T Back Pressure
- [ ] A/B Pressure
- [ ] PVP Relief Setting
- [ ] LSA/B Setting
- [ ] PVLP Setting
- [ ] Pilot Pressure
- [ ] Oil Temperature
- [ ] Oil Cleanliness

## C. Electrical
- [ ] Supply Voltage
- [ ] Connector
- [ ] Neutral Signal
- [ ] A/B Command
- [ ] Fault Output / LED
- [ ] CAN Communication(PVED)
- [ ] Spool Position Feedback

## D. Functional
- [ ] Neutral에서 오동작 없음
- [ ] A 방향 동작
- [ ] B 방향 동작
- [ ] Float 동작(해당 사양)
- [ ] Load Holding
- [ ] LS Response
- [ ] PVPX Unloading
- [ ] Emergency Lowering(PVPC 구성 시)

## E. 기록
점검 시 반드시 실제 측정값, valve code, 사진, setting 값을 함께 기록한다.
