## Troubleshooting

검색 Keyword: LOAD LIMITER, 과부하, E-Pr, E-bC, EA-C, EAb-, E---, 역상, 결상, LOAd, L.-Lo., H.-Lo.

### 증상: 과부하 TRIP 발생 (`LOAd` → `L.-Lo.` 또는 `H.-Lo.` 표시, Relay OPEN)

**Possible Cause**
- 실제 MOTOR 과부하(기계적 걸림, 정격 초과 하중 등)
- L/H상 설정 전류가 실제 부하 대비 지나치게 낮게 설정됨
- SHOCK TIME이 지나치게 짧게 설정되어 순간 기동 전류에도 TRIP

**Inspection**
- [ ] 기계 측 걸림·과부하 여부 현장 확인
- [ ] 선택 BUTTON으로 현재 L/H 설정 전류값 및 SHOCK TIME 확인
- [ ] HT/LT 시험 버튼으로 재현성 확인

**Corrective Action**
1. 실제 과부하 원인(기계적 걸림 등)이 있으면 우선 해소한다.
2. 설정 전류/SHOCK TIME이 실제 부하 조건과 맞지 않으면 Setting 절차에 따라 재설정한다(임의로 상향 설정하여 보호 기능을 무력화하지 않는다).
3. 복귀 BUTTON을 눌러 `P.0.0` 상태로 복귀시킨다.

**Final Check**
정상 부하 운전 시 L/H상 전류 표시가 설정치 이내에서 안정적으로 유지되고 재TRIP이 발생하지 않는지 확인한다.

---

### 증상: 3상 역상 감지 (`E-Pr` 표시, 연속 3회 단음 BUZZER)

**Possible Cause**
- 제어반 인입 3상 전원선의 상 순서(R-S-T) 배선 오류

**Inspection**
- [ ] 인입 3상 전원선의 상 순서 확인
- [ ] (LKDL-60 계열) 역상 상태에서는 Push Button에 의한 UP/DOWN 조작이 불가능하고, 다른 조작 시에도 ERROR MESSAGE와 BUZZER 경보가 계속됨을 확인

**Corrective Action**
1. 전원을 OFF 한다 (LKDL-60 계열은 전원 재투입 전까지 ERROR 상태가 해지되지 않음).
2. 인입 3상 전원선 중 2선의 결선 순서를 바꾸어 정상 상 순서로 재배선한다.
3. 전원을 재투입하여 `P.0.0` 정상 표시를 확인한다.

**Final Check**
전원 재투입 후 ERROR 표시 없이 `P.0.0`으로 정상 진입하고, UP/DOWN 조작이 정상적으로 가능한지 확인한다.

### 증상: 결상 감지 (`E-bC`/`EA-C`/`EAb-`/`E---` 표시, 연속 2회 단음 BUZZER)

**Possible Cause**
- 3상 전원선 중 1상(R/S/T) 또는 전 상의 단선·접촉 불량
- 제어반 내 해당 상 퓨즈 또는 차단기 트립

**Inspection**
- [ ] 표시 코드로 결상 상(R/S/T 단상 또는 전상) 식별: `E-bC`(R상), `EA-C`(S상), `EAb-`(T상), `E---`(R,S,T 전상)
- [ ] 해당 상의 배선·단자대 체결 상태 확인
- [ ] 해당 상 퓨즈/차단기 상태 확인

**Corrective Action**
1. 전원을 차단한 후 해당 상의 배선 접속 상태를 재점검·재체결한다.
2. 단선된 케이블이나 소손된 퓨즈는 교체한다.
3. 전원을 재투입하여 ERROR 표시 해제 여부를 확인한다.

**Final Check**
전원 재투입 후 `P.0.0` 정상 표시 및 L/H상 전류값이 정상적으로 변화하는지 확인한다.

---

### 증상: 과도한 인칭(Jog) 시 오동작 (연속 장음 BUZZER)

**Possible Cause**
- 인칭 조작을 짧은 간격으로 연속 반복하여 설정된 인칭 감도 시간(t)·횟수(n) 조건을 초과함

**Inspection**
- [ ] 현재 인칭 감도 설정 시간(`t 0.0`)·설정 횟수(`n 0.0`) 확인
- [ ] 실제 인칭 조작 패턴(간격, 횟수) 확인

**Corrective Action**
1. 인칭 조작 간격을 늘리거나 연속 인칭 횟수를 줄여 운전한다.
2. 현장 운전 패턴상 부득이하게 인칭이 잦은 경우, 안전관리 담당자가 Setting 절차에 따라 t/n 값을 현장 여건에 맞게 재검토·조정한다.

---

### 증상: 전원 투입 후 LED 표시창 무점등 또는 응답 없음

**Possible Cause**
- 정격 전압 불일치(AC24V/110V/220V 사양과 실제 인가 전압 상이)
- 내부 CABLE 커넥터 분리 또는 접촉 불량
- 본체 소손(운반 중 충격, 정격 외 전압 인가 등)

**Inspection**
- [ ] 명판 POWER 규격과 실제 인가 전압 일치 여부 확인
- [ ] 본체-CABLE 커넥터 체결 상태 확인
- [ ] 외관 손상(운반/충격) 여부 확인

**Corrective Action**
1. 전원을 차단하고 정격 전압 일치 여부를 재확인한다.
2. CABLE 커넥터를 재체결한다.
3. 이상이 없는데도 무점등이 지속되면 본체를 CABLE에서 분리하여 교체하고, 제조사(LK HOIST CO., LTD.)에 A/S를 의뢰한다.
