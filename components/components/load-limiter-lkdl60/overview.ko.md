## 개요

LOAD LIMITER(로드 리미터)는 MOTOR를 사용하는 기계를 충격 과부하로부터 보호하는 전기적 안전장치이다.

기계에 과부하가 걸리면 외장형 변류기(C.T)에서 검출한 MOTOR의 Current를 LOAD LIMITER가 설정치와 비교하여 과부하 여부를 판단하고, 이상 신호가 출력되면 Relay 접점이 OPEN되어 운전 전원을 차단함으로써 기계를 보호한다.

본 장비는 **LK HOIST CO., LTD.(주엘케이)의 LKDL-60A**를 기준으로 작성되었으며, 검출 방식은 Analog Type에서 Digital 검출 방식으로 전환된 1CHIP MICRO COMPUTER 제어 방식이다.

> ℹ 본 제품은 산업안전보건법상 위험기계·기구 설비로 취급부주의 시 심각한 신체상·재산상의 손해를 초래할 수 있으므로, 반드시 교육받은 유자격자에 한하여 설치·조작·점검을 수행해야 한다.

### 주요 기능

- MOTOR Current를 검출하여 과부하(충격 과부하 포함) 발생 시 Relay 접점을 차단하여 기계를 보호
- DIGITAL Type으로 설정 전류를 0.1A 단위로 정밀 조정 가능하며, SETTING 시 LED 표시창에 설정값이 표시됨
- MICRO COMPUTER 기반 복귀시간 지연 기능 및 상승시간 자동 기억 기능(동일 시간 하강 시 자동 복귀)
- 과부하 동작(TRIP) 시 저속(L상)/고속(H상)을 구분하여 표시
- 3상 역상·결상 감지 기능 및 ERROR MESSAGE 표시(단, 역상 방지 기능은 LKDL-601 계열 한정)
- 인위적으로 과부하를 만들지 않고도 동작 여부를 확인할 수 있는 시험 버튼(HT, LT) 제공
- 총 사용시간, 작동 횟수, 과부하 발생빈도, SETTING 변경값, 최근 작동 피크 전류값 Check 기능
- A/S 시 CABLE이 본체와 분리되므로 배선 제거 없이 본체 교환/A/S 가능

### 설치 위치

크레인 등 MOTOR 구동 계통의 전원 제어반 내부에 설치되며, 외장형 변류기(C.T)를 통해 MOTOR 전원선의 전류를 검출한다. C.T 접속선은 전류 오차 방지를 위해 최대한 짧게(권장 1M 이내) 배선한다.
