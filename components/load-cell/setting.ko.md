## Setting

| 항목 | Factory Default | Recommended | Adjustment Range |
|---|---|---|---|
| Rated Capacity | 50 ton | 크레인 정격에 맞춤 | 5–200 ton (모델별) |
| Zero Offset | 0.00 mV/V | 무하중 시 0에 근접 | ±0.05 mV/V |
| Rated Output | 2.0 mV/V | 제조사 성적서 값 사용 | 1.5–3.0 mV/V |
| RCL 경보 설정 | 정격의 90% | 정격의 90% | 정격의 85–95% |
| RCL 차단 설정 | 정격의 100% | 정격의 100~110% | 정격의 100–115% |

### Setting 절차 (Calibration)

1. 무하중 상태에서 Zero Point 설정 (RCL Zero Calibration 메뉴)
2. 검증된 표준 하중(Test Weight)을 단계별로 인가 (25%, 50%, 75%, 100%)
3. 각 단계에서 RCL 표시값과 실제 하중 비교, 오차 기록
4. Span(기울기) 보정으로 전 구간 오차를 규정 범위 이내로 조정
5. RCL 경보/차단 압력값을 크레인 정격에 맞게 설정

> ⚠ Calibration은 반드시 검증된 표준 추 또는 인증된 Test Weight를 사용한다. 임의의 하중으로 교정 시 안전 시스템 전체의 신뢰성이 훼손된다.

### Acceptance Criteria

전 구간(25~100%) 오차 ±1% 이내, RCL 경보/차단 지점에서 정확히 작동.
