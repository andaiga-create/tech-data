## Overview

The load cell converts the load applied to the crane hook or boom into an electrical signal, which is passed to the overload protection system (RCL/OLP).

This document is based on the **Zemic LC-500S** shear-beam load cell.

> ℹ Load cell data is directly tied to crane safety, so maintaining accuracy through regular calibration is essential.

### Key Functions

- Real-time load measurement with analog/digital signal output
- Sends alarm/cutoff signals to the RCL (Rated Capacity Limiter) on overload
- Measurement accuracy correction via calibration
