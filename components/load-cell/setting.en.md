## Setting

| Item | Factory Default | Recommended | Adjustment Range |
|---|---|---|---|
| Rated Capacity | 50 ton | Match crane rating | 5–200 ton (model-dependent) |
| Zero Offset | 0.00 mV/V | Close to zero at no load | ±0.05 mV/V |
| Rated Output | 2.0 mV/V | Use manufacturer test certificate value | 1.5–3.0 mV/V |
| RCL Alarm Setting | 90% of rated | 90% of rated | 85–95% of rated |
| RCL Cutoff Setting | 100% of rated | 100–110% of rated | 100–115% of rated |

### Setting Procedure (Calibration)

1. Set the zero point with no load applied (RCL Zero Calibration menu)
2. Apply a certified test weight in steps (25%, 50%, 75%, 100%)
3. Compare the RCL reading to the actual load at each step and record the error
4. Adjust the span (slope) to bring the error across the full range within spec
5. Set the RCL alarm/cutoff points to match the crane's rating

> ⚠ Always use a certified standard weight or approved test weight for calibration. Calibrating with an arbitrary load compromises the reliability of the entire safety system.

### Acceptance Criteria

Error within ±1% across the full range (25–100%); RCL alarm/cutoff trips accurately at the set points.
