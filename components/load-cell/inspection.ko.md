## Inspection

> ⚠ 로드셀은 크레인 과부하 방지 시스템의 핵심 부품이다. 신호 이상 상태로 크레인을 가동하지 않는다.

- [ ] Power OFF 확인
- [ ] Connector 및 케이블 손상 여부 확인
- [ ] 로드셀 본체 외관 변형/손상 확인
- [ ] Mounting Pin 및 Bracket 체결 상태 확인
- [ ] 영점(Zero) 신호 정상 여부 확인 (무하중 시)
- [ ] 과부하 이력(Overload Indicator) 확인
- [ ] 케이블 피복 및 방수 커넥터 상태 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| 외관 | 변형 없음 | 굽힘, 크랙, 부식 |
| 영점 신호 | 규정 범위 내 안정 | 드리프트, 노이즈 과다 |
| Overload Indicator | 미작동 | 작동 이력 있음 (교체/정밀점검 필요) |

> ✅ Overload Indicator 작동 이력이 있는 경우, 반드시 정밀 Calibration 및 구조 점검 후 재사용 여부를 판단한다.
