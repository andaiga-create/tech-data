# Load Cell

**Manufacturer:** HBM &nbsp;|&nbsp; **Model:** Z6FC3 / RSCC &nbsp;|&nbsp; **Category:** Electrical

Tension/compression strain-gauge sensor providing hook load feedback to the Load Moment Indicator (LMI) system.

## Function

- Measures tension in the wire rope reeving (via sheave pin) or compression under the boom base
- Outputs a mV/V strain signal amplified and converted to load value by LMI processor
- LMI combines load + boom angle/radius to calculate rated capacity and trigger overload cut-out

## Where to find it

Pin-type load cell installed at the load sheave pin at the boom head, or compression type under the crane pedestal base, depending on crane model.

> ⚠ **Heavy Load / Stored Energy** — Never work on the load cell or its pin with a suspended load on the hook.

## Related components

- LMI display/processor unit
- Junction box / signal amplifier
- Boom angle encoder (used together for capacity calculation)
