# Setting

## Setting Value

| Parameter | Value |
|---|---|
| Rated capacity | per crane nameplate (e.g. 50 t) |
| Zero-load output | 0.000 mV/V (± tolerance below) |
| Overload alarm setpoint | 100% RC (audible) / 110% RC (cut-out) |

## Factory Default

Calibration factor set at factory using certified test weights; recorded on the calibration certificate shipped with the crane.

## Recommended Value

Re-zero and span-check at every 6-month LMI calibration interval, or after load cell/pin replacement.

## Adjustment Range

Zero tolerance: **±0.5% of rated capacity**. Span error tolerance: **±2% of rated capacity** across test points.

## Procedure

1. Confirm no load on hook, boom in reference position.
2. On LMI processor, enter calibration mode.
3. Record zero-load reading — should be within tolerance of stored zero.
4. Apply certified test weight(s) at defined radius, per crane test procedure.
5. Compare LMI displayed load to actual test weight at each test point (minimum 3 points across range).
6. Adjust span factor if error exceeds tolerance; re-test.
7. Record results on Calibration Record.

## Acceptance Criteria

- Zero-load reading within ±0.5% RC
- Load reading within ±2% RC at all test points
- Overload cut-out activates at 110% RC (± crane spec tolerance)

## Warning

> ⚠ Test weights must be rigged and handled per site lifting procedure. Never use the crane's own uncalibrated reading to judge test weight safety margins.
