## Inspection

> ⚠ 점검을 시작하기 전 반드시 전원 스위치를 OFF하여 전류를 차단한다. 차단하지 않고 점검/조정할 경우 중대한 사고로 이어질 수 있다. (GAP 조정 등 조정 작업 시에도 동일하게 적용)

- [ ] Power OFF 확인
- [ ] MAGNET(1)–ARMATURE(2) 간 GAP을 360° 전 둘레에서 확인 (규정: 0.5mm)
- [ ] LINING(4) 표면에 기름·수분 등 오염 여부 확인
- [ ] GAP FIXING BOLT(5), GAP REGULATION SCREW(6), TORQUE ADJUSTABLE BOLT(7) 체결 상태 확인
- [ ] (시운전 전) MAGNET COIL에만 전원을 공급하여 축이 저항 없이 회전하는지 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| GAP | 0.5mm, 360° 균일 | 0.5mm 초과(간극 벌어짐) 또는 편차 발생 |
| LINING 면 | 건조하고 이물질 없음 | 기름·수분 등으로 오염됨 |
| 무여자 시 제동 | 스프링 압력으로 즉시 제동됨 | 제동 지연 또는 미제동 |
| 여자 시(무부하 시운전) | 저항 없이 원활하게 회전 | 걸림, 저항, 이상음 발생 |

> ℹ 라이닝이 기름이나 수분에 오염되면 제동 기능을 상실하므로, 정상 판정 시에도 오염 여부는 반드시 육안으로 확인한다.

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능. ABNORMAL 항목 발생 시 Troubleshooting 절차로 이동한다.
