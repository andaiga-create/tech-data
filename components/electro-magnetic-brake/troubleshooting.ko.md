## Troubleshooting

검색 Keyword: SLIP, 슬립, GAP, 라이닝 오염, 제동력 부족, torque

### 증상: 사용 중 SLIP(제동 지연/미끄러짐) 발생

**Possible Cause**
- MAGNET(1)–ARMATURE(2) 간 GAP이 규정치(0.5mm)보다 벌어짐 (라이닝 마모 등)

**Inspection**
- [ ] GAP을 360° 전 둘레에서 측정하여 0.5mm 기준 초과 여부 확인

**Corrective Action**
1. GAP FIXING BOLT(5) 4개소를 풀고 GAP REGULATION SCREW(6)로 GAP을 0.5mm로 재조정
2. GAP FIXING BOLT(5)를 균일하게 재체결

**Final Check**
무부하 시운전으로 축이 저항 없이 회전하는지 확인 후, 부하 시운전에서 SLIP이 재발하지 않는지 확인한다.

---

### 증상: 라이닝 오염으로 제동력 저하

**Possible Cause**
- LINING(4) 표면에 기름 또는 수분이 침투

**Inspection**
- [ ] 라이닝 표면 육안 확인 (오염·변색·습기 여부)

**Corrective Action**
1. 오염원(누유 지점 등)을 먼저 차단
2. 라이닝 표면을 세척 (오염이 심하거나 라이닝 자체 손상 시 교체는 해당 브레이크 제조사 매뉴얼 절차를 따를 것 — 본 자료에는 라이닝 교체 절차가 포함되어 있지 않음)

---

### 증상: 제동 토크 부족 (제동은 되나 힘이 약함)

**Possible Cause**
- TORQUE ADJUSTABLE BOLT(7) 조정 부족

**Inspection**
- [ ] 현재 제동 상태 및 TORQUE ADJUSTABLE BOLT(7) 체결 상태 확인

**Corrective Action**
1. TORQUE ADJUSTABLE BOLT(7)를 시계방향(CW)으로 소량씩 조이며 제동력 증가
2. 조정 시마다 시운전으로 제동 상태를 재확인

> ℹ 구체적인 조임량(토크 수치)은 제공된 자료에 없어, 현장에서 소량씩 조정하며 제동 상태를 확인하는 방식으로 진행해야 한다. 과도한 조임은 급격한 제동 충격을 유발할 수 있으므로 주의한다.

---

### 증상: 무여자 상태(전원 OFF)에서도 브레이크가 개방되어 있음 (제동되지 않음)

**Possible Cause**
- 스프링(3) 불량 또는 파손
- GAP FIXING BOLT(5)/GAP REGULATION SCREW(6) 조정 불량으로 ARMATURE가 원위치로 복귀하지 못함

**Inspection**
- [ ] 전원 OFF 상태에서 ARMATURE가 LINING 쪽으로 완전히 복귀하는지 육안 확인
- [ ] SPRING(3) 외관 손상 여부 확인

**Corrective Action**
1. GAP 재조정 절차(Setting 탭)를 재수행하여 기구적 걸림 여부 우선 확인
2. 스프링 손상이 의심되면 즉시 가동을 중지하고 부품 교체 여부를 검토 (스프링 교체 절차는 본 자료에 포함되어 있지 않음 — 제조사 확인 필요)

> ⚠ 무여자 상태에서 제동이 되지 않는 것은 낙하 사고로 직결될 수 있는 중대 결함이다. 원인이 확인되지 않으면 해당 축을 즉시 운전 정지하고 별도 낙하 방지 조치를 취한다.
