## Specifications

| 항목 | 규격 |
|---|---|
| 제조사 | 자료에 명기되지 않음 (현장 명판 확인 필요) |
| 모델 | 자료에 명기되지 않음 (현장 명판 확인 필요) |
| 작동 방식 | 무여자 작동형(Fail-Safe), 스프링 제동, DC 전자브레이크 |
| GAP 규정값 | 0.5mm (MAGNET–ARMATURE, 360° 균일) |
| GAP 조정 부위 | GAP FIXING BOLT(5), GAP REGULATION SCREW(6) |
| 토크 조정 부위 | TORQUE ADJUSTABLE BOLT(7) — 시계방향(CW) 조임 시 제동 토크 증가 |
| 적용 계통 | 호이스트 등 수직 하중 이동 계통 |
| 정격 전압/전류, 정격 토크, 사용 온도 범위 등 | 자료에 명기되지 않음 |

> ℹ 사양은 참고용이며, 실제 설치 장비의 명판(Nameplate)을 최우선 기준으로 한다.

> ⚠ 확인 필요 — 별도로 첨부된 대광산업(大光産業) DB BRAKE형 매뉴얼(참고 문서, Documents 탭)은 동일한 스프링 제동형 DC 전자브레이크 구조이나, GAP 규정값이 **0.4mm**로 본 문서(0.5mm)와 다르고, 부품 명칭도 DISK FLANGE·MAGNET FLANGE·STUD BOLT 등으로 표기 방식이 다르다. 두 문서는 서로 다른 제조사/모델일 가능성이 높으므로, 현장에 설치된 브레이크가 정확히 어느 매뉴얼에 해당하는지 명판·형식표기로 반드시 확인한 후 해당 GAP 값을 적용할 것. 본 페이지의 절차와 규정값(0.5mm)은 "브레이크 갭 조절 매뉴얼"을 기준으로 작성되었다.
