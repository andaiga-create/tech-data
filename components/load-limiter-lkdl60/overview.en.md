## Overview

The LOAD LIMITER is an electrical safety device that protects motor-driven machinery from shock overload.

When the machine is overloaded, the LOAD LIMITER compares the motor current — detected by an external current transformer (C.T) — against a preset threshold. If the current exceeds the setting, an abnormal signal is output and the Relay contact opens, cutting operating power to protect the machine.

This manual is based on the **LKDL-60A by LK HOIST CO., LTD.**, which uses a 1-CHIP MICRO COMPUTER-controlled Digital detection method (upgraded from the earlier Analog Type).

> ℹ This equipment is classified as hazardous machinery/equipment under industrial safety and health regulations. Mishandling can cause serious injury or property damage — installation, operation, and inspection must be performed only by trained, qualified personnel.

### Key Functions

- Detects motor current and opens the Relay contact to protect the machine when an overload (including shock overload) occurs
- Digital type with 0.1A precision current setting; the setting value is shown on the LED display during SETTING
- Micro-computer based return-time delay function and automatic memory of rise time (auto-recovery when the load drops within the same time window)
- Distinguishes and displays low-speed (L phase) vs. high-speed (H phase) overload trips
- Detects 3-phase reverse-phase and phase-loss conditions with ERROR MESSAGE display (reverse-phase protection applies only to the LKDL-601 series)
- HT/LT test buttons let you verify overload-trip operation without creating an actual overload
- Check functions for total operating time, trip count, overload frequency, setting-change history, and the most recent peak trip current
- The cable disconnects from the body for A/S, so the main unit can be replaced without removing wiring

### Mounting Location

Installed inside the power control panel of the motor drive system. Motor line current is detected via an external current transformer (C.T). Keep the C.T lead wiring as short as possible (recommended within 1 m) to prevent current measurement error.
