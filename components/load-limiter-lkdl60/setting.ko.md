## Setting

| 표시창 | 항목 | Factory Default | Adjustment Range | 설정 단위 |
|---|---|---|---|---|
| `5.L.0.0` | "L" SHOCK TIME | 1초 | 0.1 ⇔ 9.9초 | 0.1초 |
| `5.H.0.0` | "H" SHOCK TIME | 1초 | 0.1 ⇔ 9.9초 | 0.1초 |
| `5.5.0.0` | RESET TIME | 1.5초 | 0.1 ⇔ 9.9초 | 0.1초 |
| `L 0.0` | "L"상 설정 전류 | 용량별 설정 전류값 | 1.0 ⇔ 80A | 0.1A |
| `H 0.0` | "H"상 설정 전류 | 용량별 설정 전류값 | 1.0 ⇔ 80A | 0.1A |
| `t 0.0` | 인칭 감도 설정 시간 | 350msec | 10 ⇔ 990msec | 1msec |
| `n 0.0` | 인칭 감도 설정 횟수 | 5회 | 1 ⇔ 20회 | 1회 |

> ℹ "L"상/"H"상 설정 전류의 Factory Default는 적용 MOTOR 용량에 따라 현장에서 결정되는 값으로, 본 자료에는 고정된 기본 수치가 제공되지 않는다. 실제 설치 장비의 SETTING DATA 및 명판을 확인하여 현장 값으로 기록·관리할 것.

### Setting 절차

> ⚠ DATA 입력·변경은 내부 전면에서만 가능하며, 안전관리 담당자 외에는 조작하지 말 것. 조작이 완료된 후에는 반드시 봉인한다.

1. 전원을 투입하고 LED 표시창에 `P.0.0`(운전 준비 상태)이 표시되는지 확인한다.
2. Cover를 열어 내부 전면(설정부)에 접근한다.
3. 기억 BUTTON을 1회 눌러 SETTING 모드로 진입한다 (`C.0.0` 표시).
4. ▲ BUTTON을 눌러 LOAD LIMITER SETTING CHART 코드(`C.18`)를 확인한다.
5. 선택 BUTTON을 눌러 설정 항목을 다음 순서로 이동한다: `5.L.0.0`("L" SHOCK TIME) → `5.H.0.0`("H" SHOCK TIME) → `5.5.0.0`(RESET TIME) → `H 0.0`("H"상 설정 전류) → `L 0.0`("L"상 설정 전류) → `t 0.0`(인칭 감도 설정 시간) → `n 0.0`(인칭 감도 설정 횟수).
6. 각 항목에서 ▲/▼ BUTTON으로 원하는 값을 설정한다.
7. 모든 항목 설정이 끝나면 선택 BUTTON을 눌러 이동한 뒤, 기억 BUTTON을 1회 눌러 저장한다.
8. 새로 입력한 값이 기존 저장값과 다르면 `SAVE` 표시 후 저장되며 `P.0.0`으로 복귀된다. 기존 값과 동일하면 `ESC` 표시 후 복귀된다.
9. 설정 완료 후 Cover를 닫고 반드시 봉인한다.

> ⚠ 인칭(Jog) 조작을 연속적으로 반복하면 오동작의 원인이 되므로, 인칭 감도 설정값(t, n) 및 실제 운전 시 인칭 사용 빈도에 유의한다.

### Acceptance Criteria

- 모든 SETTING 항목이 선택 BUTTON 재확인 시 입력한 값과 동일하게 표시될 것
- 저장 시 `SAVE` 표시 후 정상적으로 `P.0.0`(운전 준비 상태)으로 복귀될 것
- HT/LT 시험 버튼 동작 시 설정한 전류값 부근에서 정상적으로 TRIP될 것
- 설정 완료 후 Cover 체결 및 봉인 상태가 정상일 것
