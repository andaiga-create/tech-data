## Inspection

> ⚠ 전원을 인가한 상태에서 본체 내부 전면(설정부)을 열어 작업하면 감전 및 오조작 위험이 있다. DATA 변경 등 내부 작업은 반드시 자격을 부여받은 안전관리 담당자만 수행하고, 작업 완료 후에는 반드시 봉인한다.

- [ ] 명판(MODEL, POWER 전압)과 실제 인가 전압 일치 여부 확인
- [ ] 전원 투입 후 LED 표시창이 `P.0.0` (운전 준비 상태)로 표시되는지 확인
- [ ] 선택 BUTTON으로 L/H SHOCK TIME, RESET TIME, L/H 설정 전류, 인칭 감도 시간·횟수 등 SETTING DATA 확인
- [ ] 외장 변류기(C.T) 배선 상태 및 접속선 길이(권장 1M 이내) 확인
- [ ] Cover 체결 및 봉인 상태 확인
- [ ] HT/LT 시험 버튼으로 과부하 동작(TRIP) 정상 여부 확인 후 복귀 BUTTON으로 정상 복귀 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| 전원 투입 표시 | `P.0.0` 표시 후 운전 준비 상태 | 표시 없음, 점멸, 또는 `E-Pr`/`E-bC`/`EA-C`/`EAb-`/`E---` 등 ERROR 표시 |
| L/H상 운전 전류 표시 | 실제 MOTOR 부하에 비례하여 `L 0.0` / `H 0.0` 값이 변화 | 값 고정, 튐(Jitter), 비정상적으로 낮거나 0 유지 |
| 과부하 동작 | 설정 전류 초과 시 `LOAd` → `L.-Lo.` 또는 `H.-Lo.` 표시 후 Relay OPEN, 연속 단음(삐 삐 삐) BUZZER 경보 | 과부하 상태에서도 TRIP 미동작 또는 BUZZER 무반응 |
| HT/LT 시험 버튼 동작 | 버튼을 설정시간 이상 누르면 과부하 상태로 정상 TRIP | TRIP 미발생 또는 복귀 BUTTON으로 복귀되지 않음 |
| 3상 배선 | 정상 배선 시 ERROR 표시 없음 | `E-Pr`(역상), `E-bC`/`EA-C`/`EAb-`(단상 결상), `E---`(전상 결상) 표시 및 3회 단음/2회 단음 BUZZER 경보 |
| Cover / 봉인 | 완전 체결, 봉인 정상 | 헐거움, 봉인 훼손 또는 미부착 |

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능하다. ABNORMAL 항목 발생 시 Troubleshooting 절차로 이동한다.
