## Inspection

> ⚠ This is a precision instrument that processes very small (microvolt-level) signals. Do not modify or operate the internals arbitrarily. Always switch power OFF before removing the board from the unit or changing any wiring. Mechanical or electrical shock is a direct cause of failure — handle with care.

- [ ] Confirm power is OFF (before any wiring work)
- [ ] Check the fuse
- [ ] Check supply voltage (within rated ±10%)
- [ ] Check terminal block contact condition (no looseness/corrosion)
- [ ] Check load cell supply voltage (+EXC to -EXC: DC±10V)
- [ ] Periodically inspect all terminal contact points (quarterly recommended)
- [ ] Check heat dissipation around the unit (no heat buildup)
- [ ] Confirm the weight display is close to zero and stable with no load (no jitter/drift)
- [ ] Confirm the POWER LED (green) is lit
- [ ] Check that ALARM/OVER LEDs are not falsely latched on

### Acceptance Criteria

| Item | NORMAL | ABNORMAL |
|---|---|---|
| Supply Voltage | Within rated ±10% | Beyond tolerance |
| Fuse | Intact | Blown / discolored |
| Terminal Block | Firmly seated, no corrosion | Loose, corroded, discolored |
| Load Cell Supply Voltage | DC±10V (within spec) | Outside spec |
| Weight Display | Stable near zero with no load | Jitter or persistent drift |

> ✅ If all items are NORMAL, the unit may return to service. If any item is ABNORMAL, refer to the matching Error Code or symptom in Troubleshooting.
