## Inspection

> ⚠ 본 장치는 미소(微小) 신호를 처리하는 정밀 계측 장비이다. 임의로 내부를 변경·조작하지 말고, 기판을 장치에서 분리하거나 결선을 변경할 때는 반드시 전원 SWITCH를 OFF한 후 작업한다. 기계적/전기적 충격은 고장의 직접적인 원인이 되므로 취급에 주의한다.

- [ ] Power OFF 확인 (배선 작업 전)
- [ ] FUSE 정상 여부 확인
- [ ] 전원 전압 확인 (정격 ±10% 이내)
- [ ] TERMINAL BLOCK 접촉 상태 확인 (풀림/부식 없음)
- [ ] LOAD CELL 공급 전압 확인 (+EXC, -EXC 양단 DC±10V)
- [ ] 각 TERMINAL 접촉부 정기 점검 (분기별 권장)
- [ ] 장치 주변 방열 상태 확인 (열 축적 없음)
- [ ] WEIGHT 표시값이 무하중 시 0에 근접하고 안정적인지 확인 (흔들림/드리프트 없음)
- [ ] POWER LED(녹색) 점등 확인
- [ ] ALARM/OVER LED 오작동(상시 점등) 여부 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| 전원 전압 | 정격 ±10% 이내 | 편차 초과 |
| FUSE | 단선 없음 | 단선/변색 |
| Terminal Block | 견고히 체결, 부식 없음 | 풀림, 부식, 변색 |
| Load Cell 공급전압 | DC±10V (규정 범위) | 규정 범위 이탈 |
| Weight 표시 | 무하중 시 0 부근에서 안정 | 값이 튀거나(Jitter) 지속 드리프트 |

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능. ABNORMAL 항목 발생 시 Troubleshooting 절차의 해당 Error Code 또는 증상을 참조한다.
