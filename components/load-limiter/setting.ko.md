## Setting

> ⚠ WEIGHT SET(하중조정) 항목은 정비 담당자 이외 임의 조작을 금한다. PASSWORD는 당사(제조사)에서 확인해야 하며, 임의 조작 시 중대한 재해가 발생할 수 있다.

### KEY BOARD 사용법

| 키 | 기능 |
|---|---|
| ▲ | 수치 증가 (누를 때마다 1씩 증가) |
| ▼ | 수치 감소 (누를 때마다 1씩 감소) |
| ▶ | 하위(오른쪽) 자리 이동, 최하위행에서 최상위행으로 순환 |
| ENTER | 입력 확정 |
| CANCEL | 입력 해제 / 상위 모드로 복귀 |

> ℹ 조정 순서: `ENTER → ▶ → [MODE 선택] → ENTER → [설정값] → ENTER`. 반드시 사용법을 처음부터 끝까지 숙지한 후 조정한다.

### MODE 파라미터

| MODE | 기능 | 입력 범위 | 비고 |
|---|---|---|---|
| AUTO | AUTO ZERO | YES / NO | 현재 임의 수치를 영점화 |
| INIT | INITIAL | YES / NO | 영점화된 수치를 초기화 |
| POIT | POINT (소수점 위치) | 0, 1, 2 | 예: 1 → 20.0Ton 형식 |
| FILT | FILTER | 0 ~ 9 | 값이 높을수록 안정적(평균치), 흔들림 감소 |
| dIuI | DIVISION (끝단위) | 0, 1, 2, 5 | 하중표시 최소 변화 단위 |
| nSIg | SIG1(HIGH)/SIG2(HIGH TIME DELAY)/SIG3(LOW) | -999 ~ 9999 | 통상 SIG1=정격 95~100%, SIG2=정격 100~105% |
| nSEt | WEIGHT SET (실하중 조정) | PASSWORD 필요 | 정비 담당자 전용 |
| n420 | 4-20mA OUTPUT | PASSWORD 필요 | Option, 최소/최대 중량·전류 설정 |
| -Ad- | A/D 값 VIEW | 0 ~ 16538 | 현재 입력전압의 A/D 값 표시 (조회 전용) |

### Setting 절차

1. **POINT 설정** — 소수점 위치를 먼저 결정한다 (예: 20.0Ton 표시 → POINT=1).
2. **AUTO ZERO** — 무하중 상태에서 영점을 잡는다. (반드시 POINT 설정 이후 실시)
3. **FILTER / DIVISION** — 현장 진동 여건에 맞게 안정도(FILTER)와 표시 최소단위(DIVISION)를 조정한다.
4. **WEIGHT SET (실하중 조정)** — HOOK에 크레인 정격의 1/2 이상 하중을 걸고 지면에서 30cm 이상 들어올린 상태에서 PASSWORD 입력 후 실하중값을 입력한다.
5. **SIG1/SIG2/SIG3 설정** — SIG1(경보 예비단), SIG2(경보, Time Delay 포함), SIG3(저하중 기준)을 크레인 정격에 맞게 입력한다.
6. **4-20mA OUTPUT 설정** (Option 사용 시) — 최소/최대 중량에 대응하는 4mA/20mA 기준점을 입력한다.
7. **A/D 값 VIEW로 최종 확인** — 실하중 인가 상태에서 A/D 값이 안정적으로 표시되는지 확인한다.

### 설치 시 주의사항 (Load Cell / 케이블)

- Load Cell에 걸리는 하중의 힘 방향이 Load Cell의 하중 포인트(↓)와 정확히 일치하도록 설치한다. 방향이 어긋나면 출력 형향(치우침) 및 하중값 흔들림이 발생할 수 있다.
- Load Cell의 고정 KEY를 정상적으로 고정한다. KEY 홈이 넓거나 깊으면 동작 중 Load Cell이 돌아가거나 밀리는 현상이 발생할 수 있다.
- Load Cell 설치 후 Grease가 정상 공급되어 Sheave 회전 시 Load Cell과 간섭이 없도록 한다.
- Load Cell/신호 케이블은 동력 케이블·모터 구동 케이블 등 고전압/동작신호 케이블과 분리 배선한다.
- 신호 케이블은 가능한 최단 거리로 배선하고, 분리가 어려우면 금속 Flexible 등으로 노이즈를 차단한다.
- 컨트롤러/컨버터 케이스는 크레인과 접지되도록 설치한다. (도장이 두꺼우면 접지 불량 발생 가능 — 접지 상태 별도 확인)
- 신호 케이블의 SHIELD는 시작과 끝 부분에서 반드시 접지하되, 구간별 J/B 박스 접지단과 이중 접지하지 않는다 (이중 접지 시 노이즈 발생 가능).
- Load Cell과 컨트롤러 간 거리가 먼 경우 4-20mA Converter(SBCA-X)를 사용한다.

### Acceptance Criteria

- AUTO ZERO 이후 무하중 상태 표시값이 0 (또는 0에 근접)으로 안정
- WEIGHT SET 완료 후 검증 하중과 표시값 오차가 현장 요구 정밀도 이내
- SIG1 < SIG2(ALARM) < SIG3 설정 관계가 크레인 정격 대비 논리적으로 일치 (경보 → 차단 순서 확인)
