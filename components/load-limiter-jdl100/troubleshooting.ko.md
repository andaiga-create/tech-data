## Troubleshooting

검색 Keyword: Load Limiter, JDL-100, JDLS-70, 과부하방지장치, 전원 안켜짐, 경보, CT 단선

> ℹ 아래 증상/조치는 제조사 매뉴얼의 "12. 사용자 교육 확인사항" 표를 기준으로 작성되었다.

### 증상: 전원이 켜지지 않음

**Possible Cause**
- 메인 전원 또는 조작 전원 미인가
- 배선 단선 또는 접촉 불량

**Inspection**
- [ ] 메인 및 조작전원 인가 여부 확인
- [ ] 배선의 단선, 접촉 불량 여부 확인

**Corrective Action**
1. 전원 배선 재확인 및 재결선
2. 단선/접촉불량 부위 수리 후 재기동

---

### 증상: 정상 동작 중인데도 경보(알람)가 울림

**Possible Cause**
- 설정치 오류(과부하 설정 전류가 실제 부하보다 낮게 설정됨)
- 모터 또는 기계적 결함(과부하 상태가 실제로 존재)

**Inspection**
- [ ] 설정치(L/H 전류)가 실제 모터 정격 및 부하 조건에 적합한지 확인
- [ ] 모터나 권상 기구에 기계적 결함(베어링 고착, 과도한 마찰 등)이 없는지 확인

**Corrective Action**
1. 설정치가 부적절하면 재설정
2. 결함 부품 발견 시 수리 또는 교체

---

### 증상: 외부 기능 스위치(L/H test, Reset 등) 동작 불량

**Possible Cause**
- 스위치 접촉 불량
- 제품 내부에 습기 또는 기름 유입

**Inspection**
- [ ] 스위치 접촉 상태 확인
- [ ] 케이스 내부 습기/오염/유분 유입 여부 확인

**Corrective Action**
1. A/S 요청 (정호엔지니어링)
2. 습기 및 기름 제거 후에도 동작하지 않으면 A/S 의뢰

---

### 증상: 전류 표시가 되지 않음

**Possible Cause**
- CT선의 단선 또는 접촉 불량

**Inspection**
- [ ] CT 결선 상태 및 저항 실측으로 단선 여부 확인

**Corrective Action**
1. A/S를 요청한다 (CT 자체 및 배선 점검 필요)

---

### 증상: 전원은 켜져 있으나 호이스트가 동작하지 않음

**Possible Cause**
- 조작전압 이상
- 조작전압 전환 탭(48V/110V 또는 110V/220V)의 위치 오류

**Inspection**
- [ ] 조작전압이 정상 범위인지 측정
- [ ] 조작전압 전환 탭의 위치가 실제 공급 전압과 일치하는지 확인

**Corrective Action**
1. A/S를 요청한다

---

### 증상: RESET을 눌러도 TRIP 상태가 해제되지 않음

**Possible Cause**
- 실제 과부하 상태가 아직 해소되지 않음
- 복귀시간(Reset Time) 경과 전 재시도

**Inspection**
- [ ] 실제 하중/전류가 설정치 이하로 내려왔는지 확인
- [ ] 설정된 복귀시간(Reset Time)이 경과했는지 확인

**Corrective Action**
1. 과부하 원인(하중 초과 등)을 먼저 해소
2. 복귀시간 경과 후 RESET 재시도
