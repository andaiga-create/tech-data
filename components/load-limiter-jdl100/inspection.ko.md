## Inspection

작업 전 아래 항목을 순서대로 확인한다.

> ⚠ 봉인(Seal)을 파손하여 설정값을 임의로 변경하지 않는다. 정호엔지니어링은 임의 개조·설정변경으로 발생한 인명사고나 기계 손상에 대해 책임지지 않는다.

- [ ] 매일 작업 전 표시창의 설정치 확인 (봉인 제거 없이 Up/Down 키 1회 눌러 순차 확인 가능)
- [ ] "L test" / "H test" 키로 저속/고속 동작 시험 실시
- [ ] CT 결선 상태 및 단선 여부 확인
- [ ] 조작전압 선택 탭(48V/110V 또는 110V/220V) 위치가 올바른지 확인
- [ ] 전원 LED / ALARM LED 점등 상태 확인
- [ ] 월 1회, 실제 하중을 걸어 과부하 트립 동작 시험 실시

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| POWER LED | 점등 | 소등 |
| 전류 표시(DISPLAY) | 운전 중 모터 전류값이 표시됨 | 전류 표시 안됨(0 또는 미변화) |
| L/H test 동작 | 시험 시 정상적으로 TRIP 및 릴레이 동작 | 시험 시 무반응 또는 오동작 |
| ALARM LED / 부저 | 과부하 시에만 점멸+경보음, 평상시 소등 | 정상 동작 중에도 경보 발생, 또는 과부하 시 무반응 |
| RESET 동작 | RESET 키로 정상 복귀 | RESET 후에도 TRIP 상태 유지 |

> ✅ 모든 항목이 NORMAL이면 정상 가동 가능. ABNORMAL 항목 발생 시 아래 Troubleshooting 절차로 이동한다.
