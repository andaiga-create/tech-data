## Inspection

Check the following items, in order, before starting work.

> ⚠ Do not break the seal to change settings without authorization. JUNGHO Engineering is not liable for injury or equipment damage resulting from unauthorized modification or setting changes.

- [ ] Check the setting values on the display before work every day (press Up/Down once, without removing the seal, to check values in sequence)
- [ ] Test low-speed/high-speed operation using the "L test" / "H test" keys
- [ ] Check CT wiring condition and for open circuits
- [ ] Check the operating-voltage selector tap (48V/110V or 110V/220V) is in the correct position
- [ ] Check the POWER LED / ALARM LED status
- [ ] Once a month, apply an actual load and test overload trip operation

### Acceptance criteria

| Item | NORMAL | ABNORMAL |
|---|---|---|
| POWER LED | ON | OFF |
| Current display | Shows the running motor current | No current shown (stuck at 0 or not updating) |
| L/H test operation | Trips and relay operates correctly on test | No response or malfunction on test |
| ALARM LED / buzzer | Flashes + sounds only on overload, off otherwise | Alarms during normal operation, or no response on overload |
| RESET operation | Returns to normal with the RESET key | Stays tripped even after RESET |

> ✅ If all items are NORMAL, the unit can be put into normal operation. If any item is ABNORMAL, go to the Troubleshooting procedure below.
