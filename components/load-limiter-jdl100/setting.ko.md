## Setting

> ⚠ 설정(MODE) 키는 전면 커버를 열어야 조작 가능하며, 취급자 및 안전관리자 외에는 조작하지 않는다. 인칭(Inching) 조작을 초당 2회 이상 연속으로 하면 오동작의 원인이 된다.

### 기능별 설정범위 및 단위

| 표시창 | 기능 명칭 | 초기설정 | 설정범위 | 설정단위 |
|---|---|---|---|---|
| d.0 1.0 | "L" "H" 기동지연시간(start delay time) | 1.5초(Sec) | 0.1~10초(Sec) | 0.1초(Sec) |
| o.0 1.0 | "L" "H" 과부하 동작시간(overload time) | 1.5초(Sec) | 0.1~10초(Sec) | 0.1초(Sec) |
| r.0 1.5 | "L" "H" 복귀시간(reset time) | 1.5초(Sec) | 0.1~10초(Sec) | 0.1초(Sec) |
| L.000.4 | 저속(L상) 설정 전류 | 모타정격전류값 | 모델 정격의 설정단위값에 의한 설정 | — |
| H.000.4 | 고속(H상) 설정 전류 | 모타정격전류값 | 모델 정격의 설정단위값에 의한 설정 | — |

### 설정 절차

1. 대기(운전준비) 상태에서 설정(MODE) 키를 1회 눌러 "L""H" 기동지연시간(d.0 1.0) 화면으로 진입한다.
2. 선택(SEL) 키로 변경할 숫자 자리를 선택하고, Up(▲)/Down(▼) 키로 값을 변경한다.
3. 설정(MODE) 키를 계속 눌러 과부하 동작시간(2회) → 복귀시간(3회) → H상 전류(4회) → L상 전류(5회) 순서로 이동하며 각 항목을 동일하게 설정한다.
4. 마지막 항목에서 설정(MODE) 키를 1회 더 누르면 부저음과 함께 대기 상태로 복귀하며, 이때 변경 내용이 저장된다.

> ℹ 한 개의 기능만 변경하고자 할 경우, 해당 기능의 수치를 변경한 후 MODE 키를 계속 눌러 표시창이 대기 상태로 복귀되어야 변경 내용이 저장된다.

### 설정 시 주의사항 (Remark)

- 기동지연시간(Start delay time)은 출하 시 1.5초로 설정되어 있다. 기동시간이 긴 경우가 아니라면 재설정할 필요는 없다.
- 복귀시간(Reset time)은 기동지연시간보다 0.2초 이상 길게 설정하는 것이 안전하다.
- 단속(1단) 호이스트에 적용 시, L상과 H상의 전류를 동일하게 설정한다(2상 전원선에서 전류를 검출).
- 2단 속도(크립형, 극변환형) 호이스트에 적용 시, L상은 저속 전류로, H상은 고속 전류로 각각 설정한다.
- 과부하 동작시간(Overload time)은 모터를 과전류로부터 보호하기 위해 기동지연시간보다 짧게 설정한다. 통상 1.5초 이내를 권장한다.

### 조작 전원 배선 시 주의

> ⚠ 로드리미터의 조작 전원은 전동호이스트/크레인 전원의 ON-OFF 스위치 상단(전원 인입측)에 연결해야 한다. 모터 ON/OFF 동작 시 조작전원이 함께 차단되면 설정값이 초기화되거나 오동작할 수 있다(첨부된 "전동호이스트 SEQUENCE" 결선도 참조).

### 설정 완료 후 확인 기준(Acceptance Criteria)

- 대기 상태 화면에서 Up/Down 키를 눌러 설정값(기동지연/과부하/복귀시간/L·H 전류)이 의도한 값으로 저장되었는지 순차 확인
- L test / H test 키로 정상 TRIP 동작 확인
- RESET 키로 정상 복귀 확인
