## Inspection

> ⚠ 밸브 점검 전 관련 액추에이터의 하중을 안전하게 지지(Support)한 상태인지 확인한다. 유압 회로 개방 시 하중이 낙하할 수 있다.

- [ ] Power OFF 및 압력 해제 확인
- [ ] PVEH 코일 커넥터 체결 상태 확인
- [ ] 코일 저항값 측정 (단선/단락 확인)
- [ ] 스풀 하우징 누유 확인
- [ ] LS 라인 및 Compensator 연결부 누유 확인
- [ ] Section 간 이상 간섭(동시 조작 시 속도 저하) 여부 확인
- [ ] Manual Override 핀 정상 작동 여부 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| 코일 저항 | 제조사 규정값 ±10% | 규정값 초과 편차, 단선 |
| 누유 | 없음 | Section 접합부 적하 |
| 응답성 | 조이스틱 입력에 선형 비례 | 불감대(Dead Band) 과다, 끊김 |

> ✅ ABNORMAL 발생 시 Troubleshooting의 해당 증상을 참조한다.
