## Pressure / Flow Troubleshooting

| Symptom | First Check |
|---|---|
| Low pressure on all functions | Main Relief / PVP setting, pump pressure |
| Low pressure on one function | LSA/LSB setting, A/B port |
| One function is slow | Speed Control, flow, spool operation |
| One function is too fast | Speed Control setting |
| Unstable movement under changing load | LS signal, pressure-control spool application |
| Pressure is normal but flow is low | Speed Control, spool travel, pump flow |

> ⚠ Pressure-control spools are used to reduce LS control instability that can occur in crane lifting/lowering and slewing functions.
