# Inspection

> ⚠ **Hydraulic Pressure** — Confirm pressure released before removing PVEH coils or fittings.

## Checklist

- [ ] Power OFF / pressure released before disassembly
- [ ] No external leakage at section joints or coil O-rings
- [ ] PVEH connector plugs fully seated, no corrosion
- [ ] Cable to each section undamaged and properly routed
- [ ] Mounting bolts (tie rods) torqued, no gap between sections
- [ ] Manual override pins move freely (test with power off, low pressure)
- [ ] No abnormal function response (jerky, delayed, or drifting movement) during function test
- [ ] End plate and inlet section free of damage

## Result

`Normal` / `Abnormal` — note which section (function) is affected.

## Notes

Test each function individually at low joystick deflection first — smooth proportional response should be evident from first movement, not a sudden jump.
