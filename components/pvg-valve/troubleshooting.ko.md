## Troubleshooting

검색 Keyword: PVG Valve, Spool Stuck, No Response, Overload, LS Pressure

### 증상: 특정 Section 무반응 (조이스틱 입력해도 동작 없음)

**Possible Cause**
- PVEH 코일 단선
- 앰프 카드 신호 미출력
- 스풀 고착(오염물 유입)

**Inspection**
- [ ] 코일 저항 측정
- [ ] 앰프 카드 출력 전류 측정 (조이스틱 조작 중)
- [ ] Manual Override로 수동 작동 가능 여부 확인

**Corrective Action**
1. 코일 단선 시 코일 교체
2. 앰프 카드 신호 미출력 시 카드 및 배선 점검
3. 스풀 고착 시 Section 분해 청소 (오일 오염도 동시 점검)

**Final Check**
전 구간 조이스틱 조작으로 선형 응답 확인.

---

### 증상: 복합 동작 시 특정 Section 속도 저하

**Possible Cause**
- Compensator 오작동
- LS 라인 압력 손실
- 펌프 유량 부족 (동시 사용 유량 초과)

**Inspection**
- [ ] Compensator 스풀 고착 여부 확인
- [ ] 단독 조작 시 정상 속도 여부 확인 (펌프 유량 문제와 구분)

**Corrective Action**
1. Compensator 청소 또는 교체
2. 펌프 유량 부족 확인 시 작업 순서 조정 또는 펌프 용량 재검토

> ⚠ Compensator 분해 시 Spring 방향 및 순서를 반드시 기록 후 작업한다.
