# PVG Valve

**Manufacturer:** Danfoss &nbsp;|&nbsp; **Model:** PVG32 / PVG128 &nbsp;|&nbsp; **Category:** Hydraulic

Proportional directional control valve bank. Each section controls one crane function (hoist, luff, slew, telescope) via PVEH amplifier and joystick input.

## Function

- PVEH electric actuator converts joystick signal to spool position
- Spool position proportionally meters flow to actuator, giving smooth speed control
- PVLP load-sensing pilot maintains standby pressure logic with pump

## Where to find it

Valve bank mounted on the crane pedestal, adjacent to the hydraulic power pack, under a protective cover.

> ⚠ **Hydraulic Pressure** — Pilot and main pressure present even at neutral. Relieve pressure before disconnecting.
> ⚠ **Electrical Hazard** — PVEH coils are energized whenever the control system is powered.

## Related components

- Hydraulic pump (load-sensing)
- Joystick / control lever assembly
- PLC (function output to PVEH amplifier)
