# Setting

## Setting Value

| Parameter | Value |
|---|---|
| Max system pressure (main relief) | 350 bar |
| Standby pressure (load-sensing margin) | 20–25 bar above max load pressure |
| Max displacement | 130 cc/rev (A11VO130) |

## Factory Default

Main relief valve factory set and sealed at **350 bar**. Do not adjust without written authorization — resetting affects crane rated capacity.

## Recommended Value

Standby (margin) pressure: **22 bar**, adjustable at the load-sensing control module on the pump.

## Adjustment Range

Margin pressure adjustable **15–30 bar** via control module set screw.

## Procedure

1. Install calibrated pressure gauge at pump outlet test port.
2. Run engine at rated RPM, no load on hook.
3. Read standby pressure with all functions at neutral.
4. If outside 20–25 bar range, adjust margin set screw on load-sensing module (CW = increase).
5. Re-check after each 1/4 turn adjustment; allow pressure to stabilize.

## Acceptance Criteria

- Standby pressure: **20–25 bar**
- Main relief trips at: **345–355 bar**
- No pressure spike or oscillation at neutral

## Warning

> ⚠ Main relief valve is sealed at the factory. Breaking the seal without authorization voids crane load certification. Contact production/QA before adjusting.
