## Inspection

> ⚠ 유압 라인 점검 전 반드시 압력을 완전히 해제한다. 잔압 상태에서 호스를 분리하면 고압 유체 분사로 인한 중상 위험이 있다.

- [ ] Power OFF 및 유압 압력 완전 해제 확인
- [ ] 펌프 외관 오일 누유 흔적 확인
- [ ] 흡입 라인(Suction Line) 에어 유입 여부 확인
- [ ] 압력 게이지 정상 지시 여부 확인
- [ ] Coupling 및 Mounting Bolt 체결 상태 확인
- [ ] 이상 소음/진동 여부 확인 (Cavitation 의심 시 흡입측 우선 점검)
- [ ] 오일 온도 및 오염도(색상, 냄새) 확인

### 판정 기준

| 항목 | NORMAL | ABNORMAL |
|---|---|---|
| 누유 | 없음 (미세 습윤 이하) | 적하(Dripping) 이상 |
| 소음 | 균일한 운전음 | 금속성 이음, 캐비테이션 음 |
| 압력 | Setting 값 ±5% 이내 | Setting 값 초과 편차 |

> ✅ ABNORMAL 항목 발생 시 Troubleshooting 절차의 해당 증상을 참조한다.
