# 점검 (Inspection)

> ⚠ **감전 위험** — 단자함을 열기 전 전원을 차단하고 LOTO(잠금/표지부착)를 적용하십시오.

## 점검 항목

- [ ] 전원 OFF 확인 (LOTO 적용됨)
- [ ] 커넥터가 완전히 삽입되어 있고 핀 부식 없음
- [ ] 케이블 피복 손상 없음, 배선 경로에 마찰 지점 없음
- [ ] 마운팅 볼트 조임 상태 양호 (플랜지 부위 유격 없음)
- [ ] 커플링/벨로우즈 균열 또는 백래시 없음
- [ ] 하우징 기계적 손상, 찌그러짐, 커버 균열 없음
- [ ] PLC 진단화면에서 센서 신호 확인 (붐 이동 시 펄스 카운트 변화)
- [ ] 단자함 내부 습기 또는 오일 유입 없음

## 결과

`정상` / `이상` — FSR 리포트에 기록하고, 어떤 점검 항목이 불합격했는지 명시합니다.

## 참고사항

- 붐을 천천히 소각도로 회전시키면서 PLC 각도값이 튐 없이 부드럽게 변하는지 확인합니다.
- 붐이 움직이는데도 신호값이 고정된 값에서 멈춰 있다면 커플링 파손 또는 A/B 채널 단선을 의심하십시오 — **고장조치** 항목 참조.
