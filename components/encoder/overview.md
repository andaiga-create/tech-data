# Encoder

**Manufacturer:** Kübler &nbsp;|&nbsp; **Model:** 8.5810 / 8.J60 &nbsp;|&nbsp; **Category:** Electrical

Rotary incremental encoder mounted on the boom hoist / luffing gearbox output shaft. Provides pulse feedback to the PLC for boom angle calculation and outreach protection (LMI).

## Function

- Converts mechanical rotation into A/B/Z quadrature pulses
- PLC counts pulses to calculate boom angle in real time
- Angle value feeds the Load Moment Indicator (LMI) and outreach cut-out logic

## Where to find it

Mounted on the gearbox output flange at the boom foot, protected by a splash cover. Cable enters through a cable gland on the underside of the cover.

> ⚠ **Electrical Hazard** — De-energize the control panel (LOTO) before opening the encoder terminal box.

## Related components

- PLC input card (pulse counter module)
- LMI display unit
- Boom angle indicator (analog backup, if fitted)
