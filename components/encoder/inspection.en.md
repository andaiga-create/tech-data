## Inspection

Check the following items in order before starting work.

> ⚠ Disconnecting the connector while power is still on may cause signal faults or electric shock. Always switch power OFF before starting.

- [ ] Confirm power is OFF
- [ ] Check connector engagement and locking
- [ ] Check cable sheath for damage
- [ ] Confirm cable bending radius is within spec
- [ ] Check mounting bolts for looseness
- [ ] Check coupling backlash and alignment
- [ ] Check housing for external damage/corrosion
- [ ] Confirm signal is received normally at PLC (A/B/Z or SSI)

### Acceptance Criteria

| Item | NORMAL | ABNORMAL |
|---|---|---|
| Connector | Fully seated, lock clip intact | Loose, broken clip |
| Cable | No sheath damage | Cracks, exposed core, pinched |
| Coupling | Backlash ≤ 0.1 mm | Noticeable play/noise |
| Signal | PLC value changes proportionally with rotation | Frozen value, jitter, no signal |

> ✅ If all items are NORMAL, the unit may return to service. If any item is ABNORMAL, proceed to the Troubleshooting procedure.
